# CASATRAFFIC AI  
[CASATRAFFIC AI](https://casatraffic-ai.up.railway.app/) is an AI-powered platform delivering real-time traffic insights and predictive analytics for Casablanca urban mobility.  
Minimal, fast, and visually refined & aesthetic — CASATRAFFIC AI empowers smarter navigation and city planning with advanced LSTM models and seamless map-based interaction.
